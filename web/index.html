Device provisioning

Configure an ESP device over Bluetooth LE.

This browser does not support Web Bluetooth. Use Chrome, Edge or Opera on desktop or Android. On iPhone and iPad, open this page in the Bluefy browser.

Power on the device and make sure it is in provisioning mode, then connect to it.

Values are sent unencrypted over Bluetooth; provision in a trusted environment. Protocol: esp-hal-provisioning BLE v1.
